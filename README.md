# 王小明｜個人設計師作品集

## 如何預覽
1. 開啟網站網址，或下載此 Repository。
2. 使用瀏覽器開啟根目錄的 `index.html`。
3. 無需安裝套件、建置工具或後端服務。

## 檔案說明
- `index.html`：網站入口與內容結構。
- `css/style.css`：色彩、排版、動畫與手機版響應式樣式。
- `js/script.js`：手機導覽選單、頁尾年份與淡入效果。

## 如何修改
- 個人姓名與介紹：編輯 `index.html` 中的文字。
- 聯絡信箱：搜尋 `example@gmail.com`，改成你的電子郵件。
- 作品展示：目前使用 CSS 製作概念視覺，可替換成自己的專案圖片與介紹。
- 顏色：在 `css/style.css` 最上方的 `:root` 修改 CSS 變數。

## 外部資源
網站不需要付費服務或外部 JavaScript 套件。CSS 使用 Google Fonts 作為字體增強；若希望完全離線，可移除 `style.css` 開頭的 `@import`，系統會使用後備字體。
